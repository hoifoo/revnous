Markup shipped by Plans 02-01 / 02-02 that these specs assert against:
- `<nav aria-label="Table of contents">` — exact string, sentence case
- visible label `<p>` containing `Table of Contents` — title case
- `<ol role="list">` with one `<li>` per visible entry, `pl-4` on `level == 3` entries
- sidebar links: `<a href="#toc-…">`
- headings: `<h2 id="toc-…">` with a trailing `<a class="toc-permalink" href="#toc-…" aria-label="Permalink to …"><span aria-hidden="true">#</span></a>`
- grid wrapper class `lg:grid lg:grid-cols-[minmax(0,1fr)_16rem] lg:gap-12`
- container `max-w-5xl` when TOC-on, `max-w-4xl` when TOC-off
- TOC-off article div: `class="prose prose-lg max-w-none mb-16 "` (trailing space inside the quotes)
- `MIN_TOC_ENTRIES = 3`, inclusive at the boundary (3 renders, 2 suppresses)

Existing spec conventions in `spec/requests/blogs_toc_spec.rb`:
- requirement ID embedded in the `describe` string, e.g. `"TOC-off short-circuit (LAYOUT-04)"`
- raw-string `include` assertions against `response.body`, not Capybara matchers
- counting idiom `expect(response.body.scan('id="toc-').length).to eq(3)`
- `create(:blog, slug:, body:, toc_enabled:, published_at: 1.day.ago)`
