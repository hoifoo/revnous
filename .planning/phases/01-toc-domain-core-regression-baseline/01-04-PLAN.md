<objective>
Wire anchor injection into the rendered `/blog/:slug` HTML — downstream of the existing view sanitizer, gated on `toc_enabled`, and structurally incapable of changing a TOC-off page.

Purpose: TOC-03's render-time half and Phase 1 success criterion #2 ("the rendered response body — not just the model attribute — contains matching `id` attributes"). The short-circuit is what turns LAYOUT-04 from "we hope the round-trip is lossless" into "the TOC-off path returns the sanitizer's own object, untouched."

Output: A body for the currently-empty `BlogsHelper`, a one-line wrap at `show.html.erb:76`, a request spec proving the anchors reach the response and never reach the database, and a full-suite regression gate including Brakeman.
