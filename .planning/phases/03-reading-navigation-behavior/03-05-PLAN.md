<objective>
Cover the two remaining behaviour clusters with browser tests: click-to-jump (offset, motion gating, focus movement) and the mobile "Contents" disclosure (responsive visibility, keyboard operability, Escape, auto-close).

Purpose: A11Y-02's entire value is that keyboard and screen-reader users land where sighted users land — that is `document.activeElement`, which nothing but a real browser can observe. A11Y-03's disclosure contract is satisfied by the native `open` attribute rather than a literal `aria-expanded`, so the test must assert the property and the observable keyboard behaviour, not an attribute string. Research measured that real Escape does NOT close `<details>` natively, which is exactly why the JS assist exists and must be regression-tested.

Output: two system spec files. Runs in parallel with Plan 04 — no shared files.
</objective>

  disclosure root: `details[data-toc-target="disclosure"]`
  disclosure trigger: `summary[data-toc-target="summary"]`
  disclosure entries: `details[data-toc-target="disclosure"] nav[aria-label="Table of contents"] a`

6.
