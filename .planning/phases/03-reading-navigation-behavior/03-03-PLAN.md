Create `app/javascript/controllers/toc_controller.js`. Import `Controller` from `@hotwired/stimulus`, add the header comment `// Connects to data-controller="toc"`, and export an anonymous default class extending `Controller`.

Declare a module-level constant `TRIGGER_PCT = 25` with a comment noting D-01's near-top 20-25% band and that the value is tunable.

Declare `static targets = ["link", "disclosure", "summary", "sidebarScroller"]`.

Order the methods exactly: `connect`, `disconnect`, `navigate`, `closeDisclosureAndRestoreFocus`, then the commented helpers `recomputeActive`, `markActive`, `atBottom`, `focusHeading`, `keepEntryVisible`, `closeDisclosure`, the `scrollBehavior` getter, and `teardown` last.

connect() — must be safe to run repeatedly (Turbo can disconnect and reconnect the same instance), so call `this.teardown()` as its first statement. Then:
  1. Resolve headings from the server-rendered links. For each element of `this.linkTargets`, take `link.hash.slice(1)`, pass it through `decodeURIComponent`, and resolve with `document.getElementById`. Skip empty ids and null results. Build `this.linksByAnchor` as a `Map` from heading id to the array of link elements pointing at it — there are TWO link sets (sidebar and disclosure), so a heading normally maps to two links.
  2. Build `this.headings` as the unique heading elements, sorted into document order with `Node.compareDocumentPosition` and the `DOCUMENT_POSITION_FOLLOWING` bit. Never sort by link order — the disclosure and the sidebar are two separate lists.
  3. Return early if `this.headings.length === 0`.
  4. Initialise `this.passed = new Set()` and `this.activeHeading = null`.
  5. D-04, before creating any observer: read `window.location.hash.slice(1)`, `decodeURIComponent` it, find the heading whose `id` matches, and call `this.markActive(match || this.headings[0])` synchronously. This prevents a visible flash of "first entry active" on a deep-link load.
  6. Create the IntersectionObserver with `threshold: 0` and `rootMargin` built as: `Math.max(document.documentElement.scrollHeight, 10000)` px on top, `0px` right, negative `(100 - TRIGGER_PCT)` percent on the bottom, `0px` left. Add a comment explaining the extended-above form: a thin band such as `-25% 0px -75% 0px` produces a root box roughly 1px tall, which headings can scroll straight through between frames leaving nothing active. `rootMargin` accepts only `px` and `%` units — `em`, `rem`, `vh`, and bare unitless `0` all throw `SyntaxError` at construction. Percentages on the top/bottom edges resolve against viewport HEIGHT in browsers, contradicting the spec's own wording; note that in the comment so nobody "fixes" it later. In the callback, add each intersecting target to `this.passed` and delete each non-intersecting one, then call `this.recomputeActive()`. Observe every heading.
  7. Register a passive scroll listener: assign `this.onScroll = () => this.recomputeActive()` and `window.addEventListener("scroll", this.onScroll, { passive: true })`. This is required, not defensive — the observer callback only fires when a heading crosses the trigger line, so scrolling the last stretch of a page fires nothing and the bottom-of-page override would never run.

Do NOT store any state on `window`. All state lives on the instance: `this.observer`, `this.passed`, `this.activeHeading`, `this.headings`, `this.linksByAnchor`, `this.onScroll`.

disconnect() — call `this.teardown()` and nothing else.

navigate(event) — the capture-phase handler bound on the wrapper. In order:
  1. `const link = event.target.closest('a[href^="#"]')`. Return immediately if there is no link or if `this.element.contains(link)` is false, so non-link clicks inside the wrapper pass through untouched.
  2. Resolve the id as `decodeURIComponent(link.hash.slice(1))` and return if it is empty.
  3. Resolve the heading with `document.getElementById(id)` and return if null. Never use `querySelector("#" + id)`: a positional fallback anchor can be a valid `id` yet an invalid CSS selector and would throw `SyntaxError`.
  4. Call `event.stopPropagation()` FIRST, then `event.preventDefault()`. The order and the capture phase are both load-bearing. Add a comment recording why: the legacy inline handler in `app/views/shared/_navigation.html.erb` binds to every `a[href*="#"]` at `DOMContentLoaded`, before the deferred ES module registers Stimulus, so on a shared target it always fires first. Capture-phase `stopPropagation()` on this ancestor is the only measured strategy that prevents the event from ever reaching the target's own listeners, and it also stops Turbo's document-level `LinkClickObserver`.
  5. `this.markActive(heading)`.
  6. `this.closeDisclosure()` — a no-op on desktop, and it must not touch focus.
  7. `this.focusHeading(heading)` BEFORE the scroll call.
  8. `heading.scrollIntoView({ behavior: this.scrollBehavior, block: "start" })`. Do not add any JS scroll offset — the inherited `prose-headings:scroll-mt-8` puts the heading exactly 32px from the viewport top and is honoured by `scrollIntoView`.
  9. `history.replaceState(history.state, "", "#" + link.hash.slice(1))` so the URL stays shareable without triggering a second scroll. Derive the fragment only from the server-rendered link's own hash, never from raw `location.hash`.

closeDisclosureAndRestoreFocus(event) — return unless `this.hasDisclosureTarget` and the disclosure is open. Then `event.preventDefault()`, set `this.disclosureTarget.open = false`, and call `this.summaryTarget.focus()`. D-11: Escape is a pure cancel, so focus returns to the trigger and must NEVER go to a heading.

recomputeActive() — if `this.atBottom()` is true, mark the LAST heading active and return (D-03). Otherwise filter `this.headings` down to those present in `this.passed` and mark the last one in document order; if none have passed, mark `this.headings[0]` (D-02, so the TOC is never in a nothing-highlighted state).

markActive(heading) — return immediately if `heading === this.activeHeading`. This idempotence guard is required: the method is driven from both the observer callback and the scroll listener and would otherwise rewrite attributes every frame. Then set `this.activeHeading`, remove `aria-current` from every element of `this.linkTargets`, look up the matching links via `this.linksByAnchor.get(heading.id)`, and set `aria-current="location"` on each of them. Resolve by anchor, NEVER by array index — `linkTargets` holds both navs, so index-based lookup is wrong. Use the token `location`, not `page`; `page` means "the current page within a set of pages", which is wrong for same-page anchors. Finally call `this.keepEntryVisible` for each matched link.

atBottom() — return `Math.ceil(window.scrollY + window.innerHeight) >= document.documentElement.scrollHeight - 2`. The 2px tolerance covers fractional `scrollY` under device-pixel-ratio and zoom. Comment that this override is empirically necessary: on a page whose final section is 40px tall, the observer reported only 3 of 4 headings as passed at maximum scroll.

focusHeading(heading) — copy Turbo's own `View#focusElement` transient-tabindex pattern: if the heading already has a `tabindex` attribute just call `heading.focus({ preventScroll: true })`; otherwise set `tabindex` to `-1`, focus with `{ preventScroll: true }`, then remove the attribute. `preventScroll: true` is mandatory — without it the focus call runs the browser's scroll-into-view algorithm instantly and cancels the smooth animation. A bare heading with no `tabindex` cannot receive focus at all.

keepEntryVisible(link) — return unless `this.hasSidebarScrollerTarget` and the container contains the link. Return unless `container.scrollHeight > container.clientHeight`, so nothing happens when the list does not overflow. Then call `link.scrollIntoView({ block: "nearest" })`. Do NOT pass `behavior: "smooth"` here — it competes with the page's own smooth scroll during a jump. This is measured not to move `window.scrollY`.

closeDisclosure() — if `this.hasDisclosureTarget`, set `this.disclosureTarget.open = false`. Do not touch focus (D-09 plus D-10: entry selection sends focus to the heading, handled in `navigate`).

get scrollBehavior() — return `"auto"` when `window.matchMedia("(prefers-reduced-motion: reduce)").matches` is true, otherwise `"smooth"`. Evaluate at call time, never cache it at connect.

teardown() — idempotent. Disconnect and null the observer, remove the scroll listener if `this.onScroll` is set and then null it, clear `this.passed`, and null `this.activeHeading`. It is public because `app/javascript/application.js` sweeps every connected controller on `turbo:before-cache` and calls it.

Hard prohibitions for this file: no `innerHTML`, no `insertAdjacentHTML`, no `outerHTML`, no `document.write`, no `eval`. The controller must never render TOC markup — entries are server-rendered and sanitized. It must not write `classList` either; the active state is expressed purely through the `aria-current` attribute and Tailwind's `aria-[current=location]:*` variants. It must not re-derive anchors (Phase 1 owns derivation server-side). It must not set `scroll-behavior` on `html` or `body`.
